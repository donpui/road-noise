GOOD MEASUREMENTS

Before you drive

1

Mount the phone

Use the same stable position for every test. Keep the microphone uncovered and away from direct airflow.

2

Start while parked

Grant permissions and start the recording before moving. Never interact with the phone while driving.

3

Keep the screen awake

RoadNoise requests wake lock directly from the Start tap. If KEEP SCREEN AWAKE appears, tap it while parked. If iOS still sleeps, set Settings → Display & Brightness → Auto-Lock to Never for the trip.

4

Compare like with like

Use the same road, speed, tires, weather, HVAC setting, and phone position for meaningful comparisons.

About the dB reading

A browser cannot access the iPhone microphone's factory calibration. RoadNoise converts the digital signal to an estimated SPL using a calibration offset. Compare it with a trusted sound meter and adjust the offset for better accuracy.

SETTINGS

Sound level & device

Place this phone beside a trusted sound meter in a steady sound field. Adjust the offset until both readings match.

Use the automatic label or enter the exact phone model for later comparisons.
